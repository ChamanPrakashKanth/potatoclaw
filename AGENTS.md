## 3. Core Architectural Principle: "Rule Zero"

> **RULE ZERO: DO NOT USE AN LLM FOR ALGORITHMIC WORK THAT CODE CAN SOLVE DETERMINISTICALLY.**

Every token sent to or generated by a 4B model on a GTX 1650 incurs latency (~11 tokens/sec) and consumes finite context. Therefore:
1. **Never use the LLM to schedule tasks**: Use the deterministic DAG Topological Sort (`scripts/potato_graph.py`).
2. **Never use the LLM to evaluate memory capacity**: Use Bounded Working Memory (BWM) with utility decay (`scripts/potato_bwm.py`).
3. **Never use the LLM to verify outcomes**: Use the Deterministic Verifier (`scripts/potato_verifier.py`) for exit codes, file sizes, regex, and AST syntax.
4. **Never send raw uncompressed output to the LLM**: Use the Observation Compiler (`scripts/potato_compiler.py`) to summarize terminal stdout and DOM.
5. **Never rely on the LLM to break infinite loops**: Use cryptographic failure signature hashing and the Loop Circuit Breaker (`scripts/potato_failure_memory.py`).
6. **Always intercept direct user commands**: Natural queries and direct tool calls (`fetch_news`, `cat`, `read`, `run`, `browser`) must execute immediately in **0.05s via Rule Zero Fast-Path** before touching the neural model.

## 5. Critical Guidelines for AI Agents Modifying Code

### A. Context & Token Budget Discipline
- **Hard context limit: 2048 tokens.**
- Never increase system prompt size with verbose instructions or large schemas. Keep system prompts $<200$ tokens.
- Keep conversational history strictly bounded (last 2 turns only).
- When a tool runs, never dump the entire output into the conversation history. Always compress with `ObservationCompiler`.

### B. Reasoning & Chain-of-Thought (CoT) Suppression
- Small reasoning models (e.g. `Spark-X2.5-4B`, `DeepSeek-R1-Distill`) produce internal thought tokens in `reasoning_content`.
- **Never leak internal thinking or meta-monologues to the user.**
- In `call_potato_agent`:
  1. If `content` is populated, use `content`.
  2. If `content` is empty and `reasoning_content` is present, check if reasoning contains a tool call. If so, extract and execute the tool.
  3. Discard internal meta-monologues containing phrases like `"previous assistant"`, `"output json"`, `"let's use"`, `"the user"`, `"is a bit odd"`.

### C. Small-Model Tool-Call Repair
- Small models frequently output single quotes (`'url'`), missing quotes around keys (`{url: "..."}`), trailing commas, or markdown fences (` ```json `).
- NEVER assume the model outputs valid JSON. Always route raw text through `repair_tool_json()` and `normalize_tool_call()` in `scripts/potato_chat.py`.

### D. Single-Slot Inference Hygiene
- On a 4GB GPU, `llama-server` MUST run with `-np 1 -fa on`. Multi-slot modes divide the 2048 context into tiny chunks and trigger catastrophic CPU LRU memory swapping (dropping speed from 12 tokens/sec to 0.6 tokens/sec).
